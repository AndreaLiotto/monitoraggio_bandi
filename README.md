## ⚙️ Setup Rapido

```bash
# 1. Installa dipendenze
npm install

# 2. Configura Supabase
cp .env.local.example .env.local
# Modifica .env.local con le tue credenziali

# 3. Esegui SCHEMA_DATABASE.sql in Supabase

# 4. Avvia
npm start
```
